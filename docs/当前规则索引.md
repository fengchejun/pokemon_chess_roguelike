## 等待集中答复的结构问题

1. 两套环境卡设置是两个独立开关、单选模式，还是其他形式？默认启用什么？是否允许两套卡在同一局同时生效？
2. 捕获的“两个可选机制”分别指哪些规则？建议明确八邻格/低血量保证与“捕获后原地可行动”是否各有独立开关；默认关闭时是否完整使用 v2 捕获规则？
3. 仓库是否为跨局永久收藏，只有战后存活并加入携带队伍的怪物才能进入？每次新开局从仓库选三只，还是保留 v2 默认五只初始候选再选三只？

## 实施与验收顺序

先固定设置及存档兼容边界，再迁移元素/物种、地形与技能；之后重做回合、捕获、奖励和 AI，最后处理 UI 与文档。每个可运行切片都运行 Godot 4.7.2 的 `res://tests/run_all.gd`，更新受影响用例，并做实际画面与回合流程检查。旧版脚本位于合并提交第一父 `ba22909^1`；迁移时以 v2 的数据、规则、运行状态、界面分层接入。
