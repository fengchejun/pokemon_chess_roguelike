## 等待集中答复的结构问题

1. 环境卡两种模式二选一，默认 v2 战前站位增益卡，不能同时启用。**已接入**。
2. 捕获范围统一为八邻格。独立开关分别控制旧版低血量门槛与必成规则、原地转我方行动；两项默认关闭，按 v2 概率与离场规则。**本轮已实现**。

## 实施与验收顺序

先固定设置及存档兼容边界，再迁移元素/物种、地形与技能；之后重做回合、捕获、奖励和 AI，最后处理 UI 与文档。每个可运行切片都运行 Godot 4.7.2 的 `res://tests/run_all.gd`，更新受影响用例，并做实际画面与回合流程检查。旧版脚本位于合并提交第一父 `ba22909^1`；迁移时以 v2 的数据、规则、运行状态、界面分层接入。
