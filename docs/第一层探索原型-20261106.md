# 第一层探索原型（2026-11-06）

本轮只替换新开局的第一层，第二、三层继续使用旧流程。局外收藏保留；升级前旧局内存档清除。原型用于验证节点回访与捕获的价值，不等于物种专长、遗物和局外成长已经完成重做。

## 怎么试玩

从主菜单开始新一局，选择三名伙伴与起始技能，选择主题后进入第一层。地图固定为4×4、16节点；含营地、首战、3个捕捉点、2个群体事件、训练家委托、宝箱、商店、Boss和5个空节点。连线稀疏且全部节点可达；营地在边缘，Boss在中心四格之一，位置开局公开。

每层暂定12行动。到达过的地点可直接回访，每次1行动；新地点须从已打通道路点亮。全部连线始终可见，点亮后即可查看节点内容、确认遭遇要求并进入；未点亮地点仍隐藏类型，Boss位置仍开局公开。普通事件进入时即可点亮相邻道路，无需先完成选项。仅看到Boss位置不能直接跳过去。空节点也消耗行动并揭示邻路；首战和委托需要解决后才能打通其后分支。后方存在绕路时仍可由另一侧探索。

行动耗尽后不会打断当前交易、奖励或战斗。结算当前节点并返回层地图时，强制进入追猎整备。追猎不能取消或撤退，开局所有敌军黑化；获胜直接通过本层。也可提前挑战正常Boss。Boss/追猎必须清空敌军和活跃巢穴，击倒或捕获Boss不再令其他敌军自动消失。

## 节点内容

| 节点 | 原型行为 |
|---|---|
| 营地 | 文字界面；3食物休息；共享仓库交换。没有地图和设施耐久。 |
| 首战 | 两名16HP普通敌人，各一招；无巢穴。胜利提供一次遗物选择。 |
| 捕捉点 | 每次进入按本局种子和访问次数固定刷新3只；我方从左侧部署，中央允许障碍。未受惊时每回合随机向四邻移动一格；攻击或投球惊动全场后，它们向地图右侧两处撤离点逃跑，留到下一次自身行动时逃脱；第8回合结束剩余目标全部逃跑。可直接离开。 |
| 群体事件 | 玩耍得到4原质和1食物；喂食2食物选择遗物；或选择主动战斗。三个处理方式互斥，完成后不重复领奖。 |
| 训练家委托 | 交付本层主物种池中的指定常见物种，永久离队；24原质、3食物和一次遗物选择。需二次确认，可从背包或仓库交付；未完成时可离开准备。 |
| 商店 | 固定库存的食物、道具、3件随机遗物；出售遗物；使用现有技能强化规则。再次进入不刷新库存。 |
| 宝箱 | 深水河、隔岸岩障与一个宝箱；使用物种机制、技能与地形到达开箱。解谜地形、障碍耐久及生命损耗保存，不能重置刷箱。到达开箱后的奖励点可拾取，离开后选择遗物。 |
| Boss/追猎 | 战前说明主要威胁，不能撤退；清场后提供两次遗物选择。捕获Boss仍能领取挑战奖励。 |

获得事件奖励前需完成奖励选择，不能退出再刷候选。满员捕获后可选择随身替换，被换下的伙伴完整送入仓库，也可以直接把新伙伴送仓库。仓库成员跨层保留。

## 验证与边界

- 原机制回归使用旧规则夹具；新版有独立的迷雾/回访/结算/追猎，以及文字事件读档/解谜持久化/捕获换人测试。
- tests/capture_exploration_flow.gd 输出实际Godot窗口截图到 outputs/exploration_v2。
- 第一层当前使用固定稀疏拓扑和样本事件；物种遭遇与遗物选择按种子随机。尚未实现全套程序化拓扑、物种特性、遗物全面重做、培养投入拆除返还和新增局外成长。
- 本轮参数是可调原型值。自动化能验证规则与路由，不能代替玩家判断首战是否足够轻松、12行动是否合适、回访是否有获得感。

本轮验证结果：Godot 4.7.2 全量回归92个用例、9113个检查点通过，无脚本错误；已渲染检查1280×720的4×4迷雾地图、营地、群体事件、委托、商店、宝箱和捕捉场景。旧局内存档已清除，局外收藏文件保留。

## 11月7日流程反馈调整

- 普通战斗需训练师回到撤离区才能撤退，区外伙伴沿用扣血、濒死与携带奖励遗失规则；捕捉、事件战斗、宝箱可直接离开；文字节点可返回；Boss及追猎禁止撤退。
- 捕捉目标周围方形距离4格内，每只存活且在场的我方宝可梦增加10个百分点，上限30；训练师、召唤物不计入。可与捕获辅助叠加，总概率不超过100%。训练师实际投球范围仍为2格。
- 普通首战、群体战与捕捉地图沿用原MapGenerator的主题权重、地形组合和安全校验；捕捉仅额外修整必要通路和撤离格。宝箱保留专门解谜结构。
- 回合横幅结束后重新刷新操作按钮，避免正常返回按钮一直保持禁用。

本次反馈验证：93个用例、9498个检查点通过，无脚本错误；实际窗口检查了全连线迷雾地图、捕捉与宝箱地图。

## 捕捉区与委托二次调整

- 委托指定本层主题主物种池的常见物种，不再一律要求可达鸭；交付检查、事件说明与回访提示共用同一选择。
- 捕捉固定3只，左侧正常部署；中央地形不再整列清空。沿用原生成器，以较少的地形修整保证陆地通路，保留中央障碍。
- 首次攻击命中或合法投球（成功、失败均可）惊动全场；受惊前每回合随机向四邻移动一格，受惊后只逃跑、不主动攻击。
- 右侧两处橙色撤离格；到达后留到下次自身行动才逃脱。玩家占位可阻挡移动，推离会清空等待，再抵达需重新等待；禁锢等移动限制继续生效。逃脱不提供击倒原质、经验和掉落。
- 八回合总上限不变为无限等待；第8回合结束剩余野生目标统一离场。受惊状态、撤离点与等待信息随战斗快照保存。

本次验证：94个用例、9953个检查点通过，无脚本错误；实际窗口确认左侧部署、三只野生单位、中央障碍、橙色撤离点及逃跑移动。

## 点亮显示与原地形生成修正

- 点亮即在层地图显示实际节点名称，确认界面可查看遭遇说明；未点亮地点仍未知，所有连线始终可见。旧存档只有unlocked的节点也按点亮处理。
- 首战和群体战不再用平地覆写原图；捕捉区不再额外随机覆盖十个格子。普通遭遇继续使用既有MapGenerator，首战低压通过少量低血敌人、单技能、无巢穴实现。
- 已保存的战场现场继续保留；尚未开战的整备地图在重新进入后使用修正生成逻辑。

本次验证：94个用例、10016个检查点通过，无脚本错误；已查看点亮显示与恢复原生成方式后的首战整备实际截图。

## 单位操作与未受惊游荡

取消双击单位打开详情，继续通过行动菜单的“查看详情”按钮打开。未受惊野生单位每回合随机向一个合法相邻格移动一格，无合法格或受控制时停留，不主动进攻；受惊后继续撤离。规划、预览和读档共用可复现的游荡方向，未受惊时停在撤离点也不会逃脱。

本次验证：94个用例、10032个检查点通过，无脚本错误；包含双击输入不弹详情、按钮查看详情、逐回合一格游荡、阻挡与控制限制、读档和重复规划方向一致。

## 按节点类型恢复撤退

普通战斗（包括林缘试炼）恢复绿色撤离区机制；训练师须在区内，区外伙伴损失25%最大生命，可能濒死并留下携带奖励。捕捉、宝箱、群体事件的主动战斗可以直接离开，不产生撤离区扣血。营地、商店、文字事件继续通过返回按钮退出。Boss及追猎保持不可撤退。

提前离开保留已获得的捕获和收益，不冒领未完成的清场奖励；旧存档的全局禁止撤退字段不再封锁上述操作。

本次验证：95个用例、10056个检查点通过，无脚本错误；包含撤离点与区外扣血、非战斗节点直接离开、捕获保留、未完成事件不发挑战奖励、Boss与追猎禁止撤退，以及旧快照恢复新规则。
