## 二、最终生效的核心机制

### 1. 技能 PP

- 每个技能拥有独立的本局 PP，跨战斗保留。
- 成功施放消耗 1 PP；预览、无效目标和失败施法不消耗。
- 吟唱在宣告成功时扣 PP，打断不返还；额外施法同样消耗 PP。
- PP 分为 `5 / 10 / 15 / 20 / 25` 五档。
- 营地基础食物休息回满携带队伍全部已学技能 PP；商人“技能药剂”在战斗中为三格内队友的每项已装备技能恢复 5 PP。
- 敌方每场以满 PP 开始，并复用同一施法消耗规则。

主要代码：`scripts/rules/combat_unit.gd`、`scripts/rules/battle_state.gd`、`scripts/run/run_state.gd`。

### 2. 57 项新版遗物

- 普通 26、稀有 21、传奇 10，共 57 项；同局不重复获得。
- 正式区域普通或首领胜利后提供 1 次遗物三选一；收集区、失败、主动撤离不发放。
- 每层商人另有 1 件未拥有遗物：普通 12、稀有 20、传奇 32 原质。
- 奖励点仍只提供分享经验，不再兑换遗物。
- 圣盾碎片、断剑各有三级进化链，升级版替换前置，避免重复叠加。
- 法师笔记、不平天秤、术之尽头等复杂遗物在结算页继续处理后续选择。

当前关键数值：

| 遗物 | 当前效果 |
| --- | --- |
| 火之碳 / 水之泪 / 草之笛 / 雷之牙 / 山之玉 | 对应属性伤害 +20% |
| 五棱玄镜 | 所有属性伤害 +30%；克制倍率改为 ×1.5，逆克制仍为 ×0.75 |
| 碰撞专家 | 碰撞伤害 +5 |
| 撞击准则 | 碰撞额外造成目标最大生命 10%，我方强制位移距离 +1 |

主要代码：`scripts/data/relic_db.gd`、`scripts/run/run_state.gd`、`scripts/rules/battle_state.gd`。  
完整边界：`docs/遗物机制-v2.md`。

### 3. 技能与伤害平衡

- 敌方技能不再承受 70% 惩罚，敌我同技能使用相同基础直伤。
- 当前主要值：火球术中心 15 / 外围 8，强化中心 20；岩崩 20；撼地 13；打雷 13；海啸 15；水炮 12；急冻光线 6。
- 水炮命中附加浸湿并触发击退。
- 急冻光线先结算伤害再冰冻首个存活目标；已冰冻目标正常受伤并解冻。
- 水魔爆改为五格十字：中心 11 且不推动，四向 8；攻击方向左右两侧继续外推，受阻时结算碰撞。
- 新增草、电、火、水、岩扩充技能，并同步 AI、目标高亮、预览、巢穴目标和回归测试。
- 已删除占位试招和旧独立技能导师；技能强化改由商人刻印完成。

当前特殊分类仍包含 5 项：

- 镜花水月
- 山岳形态
- 超魔死光
- 时镜跃迁
- 魔之钥

### 4. 捕获

- 拦截范围从 main 的 5×5 方形邻域改为 **曼哈顿距离 ≤2 的 13 格菱形范围**。
- 正交两格、斜角一格可捕获；斜角两格和直线三格不可捕获。
- 常规满血 1%，随失血线性提高，最高 60%。
- 低血量必成、捕获辅助、原地转阵营和首领庇护限制保留。

主要代码：`scripts/rules/capture_system.gd`、`scripts/data/balance.gd`。

### 5. 区域、巢穴与失败流程

- 巢穴生命为第一至第三层 `30 / 50 / 70`，敌人可消耗技能机会主动守护四邻巢穴。
- 巢穴承担至少一半伤害，其余由有效守军均分；第 9 轮起实际出生的增援无击杀经验。
- 第 8 轮结束后敌军黑化；前两层只黑化当前节点，第三层才全面占领本层非首领节点。
- 第 11 次移动起全图黑化并提升敌人等级，此后每 3 次移动继续提升。
- 普通战斗需要清敌并毁巢；首领战需要击败或捕获首领。
- 未清场撤离只扣区外成员 25% 最大生命，不解锁邻区；首领战禁止主动撤退。
- 陈旧区域、缺失出生格、旧战斗快照和残缺节点数据增加了修复迁移。

### 6. 队伍、仓库与战后结算

- 出战怪物战后保留生命与 PP；留守成员每场恢复 50% 最大生命，濒死留守一场后恢复到 5 HP。
- 仓库成员跨层保留，但本局结束默认不进入永久收藏。
- 结局页必须明确勾选要保留的仓库成员；未完成选择前不能返回菜单。
- 升级时获得刻印槽，战后按偶数级学习新技能；最多装备三招，已学技能保留在招式库。
- 击杀、捕获、参战和奖励点经验使用即时入账，失败不追回已获得经验。

### 7. UI 与反馈

- 战斗、方向技能、捕获范围、巢穴目标和吟唱固定落点在预算范围内共用真实规则。
- 保留逐次技能播放、碰撞反馈、伤害/治疗/异常飘字、速度切换和中央阶段横条。
- 整备与地图预览合并；遗物、PP、招式库和技能强化信息在对应页面展示。
- 结算页支持遗物后续选择、捕获收容、学习技能和结局仓库保留选择。
