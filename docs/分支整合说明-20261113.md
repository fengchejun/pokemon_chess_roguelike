# 2026-11-13 分支整合说明

本次以主线 `5330d0e` 为基线，整合 `origin/ooklo/v2` 的 `973f69f`。回退基线分支为 `codex/baseline-ooklo-integration-20261113`。

## 采用同伴的部分

- 57 件本局唯一遗物、获取即时效果、遗物进化及后续选择。删除旧遗物等级叠加体系。
- 全部技能基础伤害与配套技能目标调整；敌方技能伤害按完整基础值计算，取消主线原有的 0.7 倍缩减。属性、等级、状态和场景减伤仍正常结算。
- 普通技能 PP 为 5–25，消耗跨战斗保留；技能药剂为目标已装备技能恢复 5 PP，食物休整恢复技能 PP。
- 训练家捕获范围为曼哈顿距离 2 格的菱形。保留主线捕获支援、惊动和目标逃跑机制。
- 结局中携带队伍自动进入永久收藏，仓库成员由玩家逐只明确勾选保留，默认未选者放弃；仓库成员仍跨楼层保留。

## 保留主线的部分

- 三层随机探索节点与行动预算、行动耗尽后的入侵与夺回、像素美术和选中描边。
- 战斗节点没有撤退区和额外宝箱；清空目标立即进入胜利结算，没有清场后的自由探索阶段。
- 每次战斗提供一次可选的新版遗物三选一；原质和道具按节点档位生成，可逐项领取或放弃，不能通过只领取原质被迫获得遗物。
- 驻守结束按累计有效行动统一开奖，时间越久奖励数量越多、稀有概率越高。召回、遣返、过层和本局结束都能结算，原有额度与去重保留。
- 驻守及事件奖励调用新版遗物获取逻辑。需要选择成员、摧毁遗物或选择魔法时进入紧凑结算页，完成后回到原位置，不重复计算探索行动。
- 蓝火、浅草覆水、电电花、岩山等主线地形扩展继续有效。

## 存档与开发工具

- 本局存档版本升级到 22。已获得的旧池遗物清理；尚未领取的遗物选择次数保留，并改用新池候选；旧固定遗物战利品迁移到新池。该档候选全部耗尽时折算原质。
- 残缺旧区域节点补齐安全默认字段，并保留节点快照；新版随机地图不会被旧九节点模板覆盖。
- `addons/godot_ai` 源码和 `tools/playtest.ps1` 保留。项目不默认启用编辑器插件，也不注册其运行时自动加载，因此正常打开和运行游戏不会启动该插件的本机 MCP 服务；需要使用插件时再主动启用，并准备其 uv/Python 依赖。
- 试玩脚本手动运行，使用 `artifacts/playtest-user` 下的隔离存档；`-Clean` 仅清理经路径校验后的隔离目录。可通过 `-GodotExe` 指定引擎。
