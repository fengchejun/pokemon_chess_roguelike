# 战旗术语表

> 当前版本：**1.0**
>
> 规则基准日期：2026-11-04
>
> 适用范围：当前可玩版本的设计、UI、测试与讨论。术语定义以本表和[当前规则索引](当前规则索引.md)为准；数值细节以代码、README 与专项测试为准。

## 使用约定

- 正式界面使用**捕获**；“捕捉”是同义输入词，不作为正式 UI 名称。
- 一场完整冒险称为**本局**；其中的单次交战称为**战斗**。
- 一次双方行动加整轮结算称为**回合**；“轮次”在日常讨论中可指回合，但正式文档优先使用“回合”。
- 我方阶段、敌方阶段和整轮结算属于同一回合的不同**阶段**。
- “直伤”是“技能直接伤害”的简称，不包含异常状态、环境或碰撞造成的伤害。

## 一、流程与地图

| 术语 | 定义 |
| --- | --- |
| 本局 / Run | 从新局开始到胜利、失败或结束的完整三层流程。永久收藏不随本局结束清空。 |
| 战斗 | 本局中的一次交战，主要为普通战斗和首领战。事件节点可能复用棋盘，但不一定构成战斗。每场使用独立的战斗状态与最多 8 回合。 |
| 回合 / Round | 我方阶段 → 敌方阶段 → 整轮结算的完整循环。UI 中的“第 N 回合”使用此定义。 |
| 回合结束 | 整轮结算阶段完成时视为一回合结束；持续回合数在此节点推进。 |
| 阶段 / Phase | 回合内的处理窗口，包括我方阶段、敌方阶段、整轮结算和战斗结束。 |
| 楼层 | 一局三层中的一层。每层包含营地、普通战斗、事件区域与首领节点。 |
| 区域 / Region | 当前楼层的节点地图及其连线、访问次数、占领压力和资源。 |
| 节点 | 区域地图上的可进入位置，如营地、普通战斗、事件区域、商人和首领。 |
| 主题 | 每层从火、水、草、岩候选中二选一的地区风格，影响敌编成、地形权重和增援池。 |
| 营地 | 可休整、交换队伍和补给收益的区域节点。营地初期安全，入侵推进后可能被占领。 |
| 商人 | 事件区域中的设施，训练家需与其正交相邻才能交易。 |
| 自由探索 | 战斗达成条件后留在节点上的非战斗状态；行动无限、回合冻结，治疗类技能和道具受限。 |
| 入侵 | 区域访问次数达到阈值后的压力升级；会占领节点、补充驻军并提高敌方等级。 |
| 首领节点 | 每层最终战斗节点；击败首领后开启通往下一层的传送门。 |
| 传送门 | 首领被击败后出现在其格位的设施；训练家与其正交相邻后可进入。 |

## 二、队伍与单位

| 术语 | 定义 |
| --- | --- |
| 永久收藏 | 跨局保存的怪物实例、亲密度和首领之血记录。新局从收藏中选择三只；本局等级、经验和强化不继承。 |
| 携带名单 | 本局可编入战斗的怪物集合，上限 6 只。 |
| 出战 | 某场战斗中实际部署到棋盘的 1–3 只怪物。 |
| 留守 | 在携带名单中但没有参加当前战斗的怪物。 |
| 仓库 | 本局暂不携带的怪物集合；与永久收藏的同步规则不同。 |
| 濒死 | 怪物当前 HP 为 0、不能出战的状态；不同于永久消灭。 |
| 训练家 | 我方固定单位。可移动、使用道具和捕获；HP 归零时本局立即失败。 |
| 单位 / CombatUnit | 棋盘上的训练家、宝可梦或召唤物实例。 |
| 物种 | 单位的数据模板，例如小火龙、杰尼龟、小拳石。 |
| 召唤物 | 技能生成、由施法者拥有的临时单位；不进入永久收藏和普通濒死队列。 |
| 友军 | 与行动者同阵营的存活单位。 |
| 敌人 / 敌方单位 | 与我方对立的单位；包含野生宝可梦与敌方召唤物。 |
| 飞行单位 | 拥有“飞行”本场 Buff 的单位；可越过地形与障碍，并规避部分地面效果与坠落。 |
| 地面单位 | 未拥有“飞行”的单位，受地面、藤蔓和致死地形规则约束。 |

## 三、回合、行动与位置

| 术语 | 定义 |
| --- | --- |
| 移动力 | 一次普通移动可支付的路径预算，由基础移动和移动修正计算。 |
| 移动机会 | 单位每个我方阶段通常拥有的一次普通移动资格；“已移动”表示该机会已被消耗。 |
| 免费地形移动 | 冲浪、溜冰、镜花水月等状态提供的零移动力移动；按各自地形与落点规则可重复使用。 |
| 技能机会 | 单位每个我方阶段通常拥有的一次施法资格。 |
| 额外施法 | 由电力引擎等效果给予的额外施法资格，可突破本阶段已有的一次施法。 |
| 正交相邻 | 上、下、左、右距离 1 格；写为四邻格。 |
| 八邻格 | 正交与四个斜角相邻的八格。 |
| 曼哈顿距离 | `abs(Δx) + abs(Δy)`，只沿正交方向计算的最短格数。 |
| 方形邻域 | 以中心格为基准、横纵最大差值构成的方形范围；周围两格即 5×5。 |
| 连通地形 | 只能经过同种/同类地形首尾相接抵达的区域；普通冲浪和溜冰要求连通。 |
| 任意水格 | 浅水或深水均可作为目标，不要求与起点连通；“镜花水月”使用此规则。 |
| 落点 | 技能、击退、召唤或传送最终选择的格子。 |
| 击退 / 推击 | 沿指定方向强制位移。位移目标被占据或阻挡时可能发生碰撞。 |
| 撤回 | 在我方阶段撤销最近一次移动，并恢复移动前状态；成功施法后通常提交移动。 |
| 行动面板 | 选中单位后出现的移动、技能、捕获、道具或设施互动入口。 |

## 四、属性、伤害与反馈

| 术语 | 定义 |
| --- | --- |
| 属性 | 当前规则属性为火、水、草、岩、电；冰招式归水，风招式归电。 |
| 克制 | 属性相克时的技能直接伤害倍率，当前为 ×1.25。 |
| 抵抗 / 逆克制 | 被目标属性克制时的技能直接伤害倍率，当前为 ×0.75，且实际伤害至少为 1。 |
| 技能直接伤害 / 直伤 | 由技能命中产生的直接 HP 损失，可触发属性倍率、技能强化和遗物效果。 |
| 实际伤害 | 完成属性、敌方系数、遗物、减伤和上限处理后的最终 HP 损失。 |
| 环境伤害 | 由地形或非单位来源造成的伤害，如燃烧、寄生、坠落或溺水。 |
| 异常状态伤害 | 由灼烧、寄生等状态持续效果造成的伤害；不属于技能直伤。 |
| 碰撞伤害 | 推击、冲锋等强制位移撞到单位、障碍或边界时追加的伤害。 |
| 致死地形 | 进入后会立即倒下的地形，如深水、深坑或熔岩；飞行及特定单位可免疫部分效果。 |
| 效果拔群 | UI 对克制技能命中时的反馈，表示本次直伤使用了 ×1.25 倍率。 |
| 效果不佳 | UI 对抵抗技能命中时的反馈，表示本次直伤使用了 ×0.75 倍率。 |
| HP / 生命 | 单位当前生命值；敌方 HP 归零时淘汰，我方宝可梦 HP 归零时濒死。 |
| 最大生命 | 单位生命上限。可由成长、首领强化或鼓舞改变；治疗只恢复当前生命。 |

## 五、技能与吟唱

| 术语 | 定义 |
| --- | --- |
| 基础技能池 | 物种在开局选择界面上可直接选作起始技能的招式集合。 |
| 可学技能池 | 单位达到偶数级后，按自身属性可从成长界面学习的招式集合。 |
| 招式库 | 单位在本局已经学会的全部技能；可超过装备上限。 |
| 装备技能 | 当前战斗中实际可用的技能，最多三招。 |
| 起始技能 | 新局开始时从基础技能池中选择并装备的一招。 |
| 特殊技能 | 不能通过开局选择、升级学习、基础技能池或其他常规成长渠道获得的技能；只能由事件、专属奖励或调试等特殊渠道提供。 |
| 占位试招 | 尚未完成正式设计的属性试招；当前为射程 2、单体 10 点基础直伤。 |
| 等级上限 | 当前楼层允许达到的最高等级，三层依次为 Lv5/Lv8/Lv10。超过上限的经验保留，换层后自动突破。 |
| 三招选一 | Lv2/4/6/8 自动获得刻印槽后，从三个当前尚未掌握的普通技能候选中选择一招学习。 |
| 刻印槽 | 本局技能强化容量。Lv2/4/6/8 各获得 1 个，单局最多 4 个；每次商人技能强化消耗 1 个空槽。 |
| 技能强化 | 对某一招进行的本局永久强化；同一招最多一次。 |
| 专属强化 | 只对指定技能生效的强化，如“镜水长明”“长浪”。 |
| 商人技能强化 | 在技能商人处指定一只当前携带宝可梦和一招已学技能，消耗空刻印槽与 12 原质进行强化；亲密度最多减免 4，最低支付 4。 |
| 特性强化 | Lv10 的成长入口。当前只记录已领取状态，不发放刻印槽、技能或生命值以外的实际效果。 |
| 连续伤害 | 一次伤害分多次生效。每段独立经过属性克制、增减伤与受击结算；目标中途倒下时停止后续分段。 |
| 炎袭 | 跃迁到全图未被占用、可站立的燃烧格，并攻击落点周围八格。 |
| 风怒炎息 | 覆盖正前方两排共八格，对敌人造成直伤并沿远离施法者方向击退。 |
| 炎炉拳 | 攻击近身敌人；根据目标是否灼烧改变自身治疗量并清除灼烧。 |
| 天火 | 在全图指定中心，生成五格十字魔法火焰并攻击范围内所有单位。 |
| 爆燃 | 攻击两格内敌人；目标灼烧时提高基础伤害并清除灼烧。 |
| 燃尽 | 攻击曼哈顿 5 格内一名敌人；目标受施法者最大生命一半的基础直伤并可能灼烧，施法者随后损失最大生命一半的当前生命。 |
| 水魔爆 | 在曼哈顿 4 格内越过障碍选择落点，以五格十字伤害并向外击退敌人。 |
| 冰之息 | 选择正交方向，覆盖前方 3 格宽、2 格深的 3×2 区域；区域内每名敌人结算伤害，浸湿目标消耗浸湿并施加一回合冰冻。 |
| 急救 | 为曼哈顿 2 格内一名受伤友军或自己恢复 8 HP，不超过生命上限；专属强化提高至 13 HP。 |
| 落地生根 | 将自身周围含脚下格的 3×3 有效低地转为草丛；强化后为 5×5，不覆盖障碍、树木、水域、冰面、熔岩、深坑、巢穴或设施。 |
| 叶之风 | 攻击曼哈顿 2 格内一名敌人。施法者位于草丛或藤蔓时，基础直伤由 8 提高至 12；强化后两档为 12／16。 |
| 解药 | 解除曼哈顿 2 格内一名友军或自己的可解除异常并恢复 3 HP；冰冻除外，专属强化提高至 8 HP。若在藤蔓格上结束禁锢且仍停留，会重新按藤蔓规则安排隔回合触发。 |
| 磁吸 | 自动选择四正交方向 5 格内最近且可见的敌人并向施法者拉近 1 格；目标有感电或麻痹时拉近 2 格，路径受障碍或中间单位阻挡。 |
| 眩光 | 对自身周围 3×3 内所有敌人施加一层感电；麻痹中的敌人不受该感电影响。 |
| 电磁镭射 | 对四正交方向 4 格内一名敌人造成 12 点基础直伤；普通目标受地形障碍阻挡，感电/麻痹目标可越障，但不能穿过中间单位。 |
| 电共鸣 | 读取自身周围 3×3 内每名单位的感电或麻痹，为施法者下一次实际技能伤害蓄积 3 或 5 点；不会消除感电与麻痹。 |
| 电极火花 | 沿选定正交方向攻击 3 格内所有敌人；命中前已有感电或麻痹的目标额外尝试获得烧伤。 |
| 拓印 | 岩系普通技能，复制曼哈顿 5 格内一名单位最近的普通技能并即时打出，不保存复制招式；基础不能复制已强化技能，且不能复制特殊技能或另一拓印。 |
| 山脉连袭 | 攻击正交相邻敌人；基础 2 段，施法者 3×3 内每格岩障增加 1 段，每段 4 点连续伤害。 |
| 山岳形态 | 岩系特殊技能；持续一回合的自身增益，3×3 内友军与自身伤害减免三分之一，剩余伤害转移给施法者。 |
| 守岩 | 为自身或曼哈顿 3 格内一名友军施加 10 点护盾，持续两回合；护盾破坏时，目标四邻格敌人各受 4 点固定伤害，不清除障碍耐久。 |
| 岩爆弹 | 攻击正交 3 格敌人，主弹 12 伤害并击退，随后向垂直两侧分裂 3 点伤害弹。 |
| 水滴石穿 | 以连续岩障延伸射程并逐格扣耐久，主伤害 12；浸湿目标额外受 3 点水属性伤害。 |
| 疯狂藤蔓 | 在所选方向前方生成藤蔓；基础 2 格，强化后 3 格，障碍与巢穴格会被跳过。 |
| 吟唱 | 先宣告、下一本方阶段才结算的跨回合技能行为。 |
| 宣告 | 吟唱技能选择并锁定落点或范围的时刻。 |
| 释放 / 落下 | 已宣告吟唱在后续本方阶段实际结算。 |
| 固定落点 | 吟唱时锁定、之后不随单位移动的格子。 |
| 吟唱打断 | 施法者倒下、冻结或麻痹时取消尚未释放的吟唱。 |
| 吟唱锁定 | 开始吟唱的单位在结算阶段不能行动的代价。 |

## 六、状态与特殊效果

| 术语 | 定义 |
| --- | --- |
| 状态 | 附着在单位身上的持续规则，如灼烧、浸湿、麻痹、护盾或镜花水月。 |
| 可解除异常 | 解药等净化效果可处理的减益集合：灼烧、浸湿、感电、麻痹、定身、禁锢、延迟藤蔓触发与寄生。冰冻和正向 Buff 不在其中。 |
| 本场 Buff | 仅持续当前战斗的单位增益，与遗物和技能强化不同。 |
| 灼烧 / 烧伤 | 持续两个回合，每次整轮结算损失最大生命 10%（向上取整、至少 1）；进入水域可解除。 |
| 浸湿 | 持续两回合，移动力 −1；重复施加刷新持续时间。水系单位与“净化”免疫。非水系冰冻目标受到实际火系技能伤害后解冻并获得浸湿。 |
| 感电 | 电系状态层。已有感电再获得一层时转为两回合麻痹并清空感电；处于麻痹时不能施加感电。 |
| 麻痹 | 使单位暂时无法移动和施法，按行动阶段衰减；麻痹期间不能施加感电。 |
| 电共鸣蓄伤 | 电共鸣为下一次造成实际技能伤害保留的增伤；命中后一次消耗，范围技对每名命中目标应用完整数值。 |
| 护盾 | 用于抵挡伤害的独立耐久。护盾优先于 HP 吸收最终伤害；持续两回合，未破坏时在第二次整轮结算结束后消失。重复施放刷新耐久与时限，不叠加。 |
| 定身 | 取消目标下一次移动机会。 |
| 禁锢 | 持续两回合，使目标不能普通移动，但不阻止技能、捕获或其他非移动行动；位移技能与击退不会提前解除。来源藤蔓格消失时立即解除。 |
| 藤蔓束缚 | 旧版状态名称；藤蔓的现行效果统一为“禁锢”，该词仅用于旧存档字段说明。 |
| 冰冻 | 持续一回合，使单位不能移动或施法；受到实际伤害时立即解除，但本次伤害正常结算。 |
| 融冰浸湿 | 非水系冰冻目标受到实际火系技能伤害后解除冰冻，并获得一层浸湿；水系目标只解冻。零伤害和技能免疫不触发。 |
| 冰冻连携 | 先要求目标浸湿，再清除浸湿并施加冰冻；当前只有冰之息的技能标签启用该连携。 |
| 加速 | 下一次可用移动机会移动力 +2。 |
| 首领鼓舞 | 首领首次降至半血时给其他敌人及后续增援的永久本场增益。 |
| 镜花水月 | 持续三回合的自增益：零耗水格跃迁、水/冰技能基础直伤 +5，并可在首次实际受伤时提前消耗以免疫该次伤害。 |
| 山岳形态 | 岩系特殊技能提供的正向增益，持续一回合。施法者周围 3×3 内友军与自身受到的最终伤害减免三分之一并转移给施法者；解药不会清除。 |
| 净化 | 免疫灼烧与浸湿并清除已有两种状态的本场 Buff。 |

## 七、成长与经验

| 术语 | 定义 |
| --- | --- |
| 参战经验 | 非失败战斗中，每名原出战成员固定获得 1 点，与该成员在本场是否击杀无关。 |
| 击杀经验 | 击败普通敌人时给实际击杀者的完整经验，公式为 `1 + ceil(敌人等级 / 2)`。 |
| 参与经验 | 其他原出战成员从同一次击败中获得的经验，为完整击杀经验向下取整的一半，至少 1。 |
| 等级经验梯度 | 敌人等级越高，完整击杀经验与其他成员的参与经验越高；Lv1/3/5/7/10 的完整击杀经验分别为 2/3/4/5/6。 |
| 首领击杀加成 | 首领给实际击杀者额外 2 点完整经验；这项加成只属于击杀者，不影响其他成员的参与经验。 |
| 召唤物经验 | 敌方召唤物被击败时给每名原出战者各 1 点，不按召唤物等级计算。 |

## 八、地形与环境

| 术语 | 定义 |
| --- | --- |
| 平地 | 无额外通行或战斗效果的基础地形。 |
| 浅水 | 可通行的水格；阶段交接时可使其中单位获得浸湿。 |
| 深水 | 对非水、非飞行单位可致死的水格；水系单位可安全进入。 |
| 草丛 | 可燃烧、可提供远程掩体的地形。 |
| 藤蔓 | 可燃烧、可暂时覆盖其他地貌的地形。地面单位进入时获得禁锢；停留不刷新，结束后仍在同格则隔一回合再次触发，离开后重入则立即触发。 |
| 冰面 | 可触发回合末滑行的地形，并可能向相邻水域扩张。 |
| 岩障 | 高耐久障碍，阻挡移动与普通射线。 |
| 树木 | 低耐久障碍，阻挡移动与普通射线，破坏后可能产生粮食。 |
| 易碎地块 | 受撼地等效果影响后可塌陷的地形。 |
| 深坑 | 地面单位进入后立即倒下的致死地形。 |
| 熔岩 | 地面单位进入后立即倒下的致死地形。 |
| 蒸汽 | 水面覆盖状态；持续两次整轮结算，站在其中的单位不能施法。 |
| 燃烧格 | 带有剩余持续回合的火格；地面单位落到其上立即获得两回合烧伤，效果刚好结束时仍在格上会重新获得。天火可生成保留底层地形的魔法燃烧格。 |
| 魔法火焰 | 由天火生成、可存在于不可燃地形上的临时火焰；保留两轮，到期后恢复原地貌。 |

## 九、捕获、巢穴与首领

| 术语 | 定义 |
| --- | --- |
| 捕获 | 训练家对敌方单位发起的收服尝试。正式 UI 使用“捕获”；“捕捉”是同义词。 |
| 捕获范围 | 训练家周围两格的 5×5 方形邻域。 |
| 捕获概率 | 常规为满血 1%，随目标已损失生命比例线性提高至最高 60%。 |
| 必成捕获 | 低血量规则开启时，5 HP 目标或 10 HP 且带减益目标直接成功；属于概率外例外。 |
| 捕获辅助 | 商店消耗品，使下一次捕获概率增加 20 个百分点。 |
| 离场捕获 | 捕获成功后目标离开战场的默认处理方式，进入战后收容流程。 |
| 原地转阵营 | 可选捕获规则；成功后目标在合法情况下留在原格并立即转为我方。若目标位于巢穴格，会移到附近合法格。 |
| 战斗目标 | 普通战斗中“清场”或“毁巢”任一条件；达成后节点解锁并可进入自由探索。 |
| 清场 | 击败或捕获全部普通敌人；不要求摧毁仍在的巢穴。 |
| 毁巢 | 将所有存活巢穴耐久降为 0；不要求清空仍存活的普通敌人。 |
| 巢穴 | 敌方增援来源，我方不能占据。清场或毁巢任一条件达成区域目标。敌方占巢时暂停产怪并保护巢穴，须先击杀占据者。 |
| 未诞生怪物经验 | 我方毁巢时，积压及后续第 2/4/6 回合尚未兑现的产怪名额；每只按 2 XP 计入战后共享经验，另加巢穴自身 3 XP。 |
| 出生轮待机 | 新生成敌人当回合不能移动或施法的规则。 |
| 首领 | 每层最终敌人的强化版本，具有额外生命和半血鼓舞。 |
| 首领之血 | 捕获首领并清场获胜后获得的永久资源；当前用途尚未完成。 |

## 十、成长、奖励与资源

| 术语 | 定义 |
| --- | --- |
| 经验 / XP | 本局成长资源；达到偶数级时获得技能强化或学习新技能的选择。 |
| 等级 | 本局怪物强度阶段，Lv1–Lv10；我方每级平滑增加最大生命，敌方仍只在奇数级增加。 |
| 亲密度 | 永久收藏记录；非失败战斗后增加，每 5 点使技能商人强化价格降低 1 原质，最多减 4。 |
| 遗物 | 本局常驻的三级构筑物，只强化我方对敌效果，不跨局继承。 |
| 消耗品 | 本局背包中的一次性地图、环境或战斗辅助物品。 |
| 原质 | 区域货币，用于商人交易。 |
| 食物 | 本局持有的休整资源，用于营地恢复；不跨新局继承。 |
| 粮食 | 战斗棋盘上可拾取的资源单位，不等同于背包中的“食物”总数。 |
| 奖励格 | 守点到敌方阶段结束可取得额外战后选择的格子。 |
| 三选一 | 从三个候选遗物或补给中选择一个的界面流程；捕获收容处置另称“捕获收容选择”。 |
| 补给点 | 每完成两场战斗后的奖励页面。 |
