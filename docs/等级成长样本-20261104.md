# 等级成长固定样本（2026-11-04）

本次按确认方案实现递增生命，等级不自动增加伤害。样本显示越级难度增加，同时同等级高等级的无构筑战斗显著变长，不能据此认定战斗时长已达到理想范围。

## 可复现条件

运行 `Godot --headless --path . --script res://tests/sample_progression_pressure.gd`，结果写入 `outputs/progression_mentor_20261104/balance_samples.json`。脚本直接调用真实 `BattleState.damage_unit`，使用三只岩系起始宝可梦对一只或三只岩系野生怪，固定顺序集火，玩家先手。双方每轮每名存活者命中一次基础10点岩系技能，敌方沿用70%直伤比例，故实际7点。

旧曲线只替换初始最大生命为基础值加每两个等级10点，其他结算完全相同；新曲线使用当前实现。为单独观察血量影响，关闭经验升级，不模拟移动、技能选择、导师强化、遗物、控制、捕获、巢穴、环境与第八轮天雷。这是固定伤害交换压力样本，不是完整AI实战胜率。

## 三对一结果

| 玩家/敌方等级 | 旧曲线轮数 | 新曲线轮数 |
| --- | ---: | ---: |
| Lv1/Lv1 | 1 | 1 |
| Lv1/Lv5 | 2 | 3 |
| Lv3/Lv5 | 2 | 3 |
| Lv5/Lv5 | 2 | 3 |
| Lv5/Lv7 | 2 | 4 |
| Lv7/Lv7 | 2 | 4 |
| Lv10/Lv10 | 3 | 6 |

三对一均胜且三名玩家存活。人数优势仍可抵消等级差：Lv1三人对Lv5单人仍三轮取胜；同为三对三时，Lv1对Lv5由旧曲线险胜变为失败，等级压制更明显。

同级Lv5由6轮增加到8轮，Lv7由6轮增加到12轮，Lv10由8轮增加到20轮。实战的地形击杀、导师强化及遗物可缩短战斗，天雷也会改变后半程，因此不能把这些轮数直接当作实战时长；同样不能用这些机制的存在来断言高等级战斗不会拖长。本次保留已确认曲线，后续应以有代表性的完整地图、实际输出构筑及导师可达性继续比较。

## 本次验证

自动回归覆盖即时经验、跨多级加血、濒死保留、事件去重、旧档补记、学习机会、导师付款和存档失败回滚。实际Godot窗口检查导师选择界面、成功服务后费用12→20，以及战斗中训练家与宝可梦即时升到Lv2、宝可梦5→11 HP和经验条变化。原始截图保存在本机 `outputs/progression_mentor_20261104/mentor.png` 和 `level_up.png`；截图与生成结果不混入机制提交。
