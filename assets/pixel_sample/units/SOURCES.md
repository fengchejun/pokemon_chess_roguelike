# 补充单位像素素材

PNG 文件来自 https://github.com/PokeAPI/sprites/tree/master/sprites/pokemon ，文件名为全国图鉴编号。
训练家来自 https://play.pokemonshowdown.com/sprites/trainers/red.png 。
素材版权属于各自权利人，本项目未将这些图片声明为原创或获得商业授权。

树人使用 709（朽木妖）作视觉替身，不改变树人的规则、属性或名称。
波波、雪童子的不同规则条目复用同一素材。已认可的四个初始伙伴仍使用 atlas-v1.png。
运行时根据非透明像素边界裁切，统一置于 96x96 的显示区域；所有图片与轮廓采用邻近过滤。

曾尝试生成 18 格角色图集，服务在输出阶段拒绝，未得到图集；没有使用失败输出。
