# 地区普通地面与液态岩浆

使用内置image_gen，参考原atlas-v1.png生成biome-ground-v1.png。原图保留，采用2×2 AtlasTexture分区。

提示规格：四格顶视正方形材质，无缝隙、文字、边框或等角体积；匹配原图的低饱和像素簇、左上光源，缩小到112×76菱形时仍清楚。纹理克制，禁止密集碎点与繁复纹样。

- 左上：森林普通泥土，深暖棕色压实土壤，少量浅土纹、边缘一两片落叶，大面积中心安静；不要碎石、覆盖整格的树根或草毯。
- 右上：湖岸普通沙地，温暖金米色，角落少量低起伏沙纹，不放贝壳、石子、水面或蓝色反光。
- 左下：真正致命的熔岩，主要为持续流动的橙红液体与宽阔黄橙热流，只留少量暗色结壳；明确区别于冷岩石中的细熔缝。
- 右下：备用湿泥土变体，深褐色、少量大块湿润区域，无石子。

火谷普通地面复用terrain-nest-v1.png的旧熔岩格（暗色岩面与少量熔缝）；岩窟普通地面保留atlas-v1.png的碎石格。游戏的平地/熔岩地形编号和规则没有改变。
