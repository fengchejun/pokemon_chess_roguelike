# 宝可梦战棋肉鸽（战旗 · 初版）

Godot 4.7 / GDScript 的 2D 战棋肉鸽。按《宝可梦战棋肉鸽完整设计方案 v2.0 定稿》
（见 `docs/`）实现：五属性克制、六类地形、威胁预告、概率捕获、濒死与持续战损。
冒险＝从开始战斗到回到基地：出战过的宝可梦在冒险结束恢复 30% 生命，留守基地的成员与仓库回满 100%；训练家每次冒险前回满生命值。

## 运行

1. 用 Godot 4.7 打开本目录的 `project.godot`，按 F5 启动；或命令行：
   `godot --path .`
2. 主菜单 →「新的一局」→ 编队（出战名单 6 只；每场勾选 1 至 3 只作战）→ 地图预览与改造 → 战斗 → 战后结算 → 下一场。
   每次冒险结束（战斗结算、回到基地）：出战过的宝可梦恢复 30%，留守基地的成员回满；每 2 场冒险先进入补给点，随后进入下一场编队。
   开局需在整备界面手动勾选出战宝可梦，未选择无法进入地图预览。

## 战斗操作

- 点击己方单位选中：蓝色格为可移动范围（数字为移动力消耗），点击格子移动；
  移动可按“最近一次移动优先”逐步撤回，施放技能 / 捕获 / 结束回合即提交行动。
- 点击技能按钮进入瞄准：金色格为有效目标；悬停任意目标格可预览结算
  （伤害含克制修正、推击方向、地形变化）；右键或 Esc 取消瞄准。
- 训练家在 2 格内可用「捕获」：成功率随目标生命降低而升高（满血 30% 起），每回合 1 次，
  成功即刻入队（保留剩余生命）。
- 「结束回合」后敌方按其预告执行（预告与实际完全一致）；「显示威胁预告」可开关；
  红色骷髅表示致死威胁。
- 「战斗失败」（训练家倒下触发的强制撤退）：不结算本场经验，出战宝可梦生命减半（不致死）并退回基地（捕获保留）。
- 战后恢复：出战过的宝可梦在冒险结束恢复 30% 生命；留守基地的成员与仓库回满 100%；训练家每次冒险前回满。
- 出战名单：上限 6 只；捕获使名单超过 6 只时，战后结算可选择「替换」名单成员或「放入仓库」。
- 补给点：每完成 2 场战斗进入；展示队伍、仓库与战损记录，待办随存档持久化。

## 已实现范围（对照方案第 12 节阶段 0 至 6；基地部分已按后续要求移除）

- 属性：火克草、草克岩、岩克电、电克水、水克火；克制 +1 / 逆克制 −1（最低 1），只作用于直接伤害。
- 地形：平地、水面、深水、草丛、障碍、熔岩；推入深水/熔岩即淘汰，障碍耐久 2。
- 技能：火种、闪焰冲锋、水流、造雨术、放电、电光步、播种、吸取、推击、碎岩、造岩（共 11 个）。
- 状态：定身、减速、灼烧；回合结构、巢穴增援（第 2、3 回合）、第 8 回合野生逃离（战斗上限 8 回合）。
- 环境卡（站位增益）：不再影响地图生成；每场战斗前在**地图预览界面**从 5 张中自选 2 张生效
  （其他界面不显示卡片信息），增益只对我方生效——水域穿行、草丛伏击、障碍掩体、
  必死格邻位庇护等（详见 `docs/实现说明.md` 第 17–19、22、23 条）。
- 地图生成：只由区域与种子决定（与卡组无关），地貌按“簇 / 带 + 散点”生成且总量受限
  （≤非保护区域 38%）；预览后可进行 2 次地形改造——注水 / 种草 / 立岩 / 开垦 / 深水 / 熔岩
  六种工具，悬停显示该格的结算内容。
- 战损与持久化：战斗倒下进入濒死（跨存档持久、留守一个冒险周期后恢复）、持续生命、战损记录、奖励携带者生命周期、存档（濒死当帧写入）。
- 战后结算：经验（击败 2 / 捕获 2）、奖励携带者存活额外 +2 经验、仓库与满载二选一。
- 战后恢复：出战过的宝可梦在冒险结束恢复 30%；留守基地的成员与仓库回满 100%（濒死者需留守一个冒险周期后恢复）；训练家每次冒险前回满。
- 出战名单与捕获处理：名单上限 6 只，每场勾选 1 至 3 只作战；捕获在战后结算——未满自动入队，
  满员时选择替换（被替换者入仓库）或放入仓库；仓库满时可放生或放弃捕获。

## 测试

```powershell
# 全量规则与界面检查（500+ 项断言，含解析检查）
& '…\godot.exe' --headless --path . --script res://tests/run_all.gd

# 可选：过滤用例，如 t05
& '…\godot.exe' --headless --path . --script res://tests/run_all.gd -- t05

# 视觉验证：开窗口跑一遍全流程并截图到 artifacts/
& '…\godot.exe' --path . -s res://tests/capture_shots.gd
```

## 目录结构

- `scripts/data/`：数值与配置（平衡、属性、地形、技能、物种、环境卡、关卡）。
- `scripts/rules/`：规则层（战斗状态、技能结算、推击、寻路、AI 与威胁预告、地图生成、捕获）。
- `scripts/run/`：一局状态与存档。
- `scripts/ui/`：全部界面与棋盘绘制（代码构建，无外部素材）。
- `scenes/main.tscn`：唯一场景入口，`scripts/main.gd` 负责界面路由。
- `tests/`：`run_all.gd` 全量检查、`cases/` 用例、`capture_shots.gd` 截图验证。
- `docs/`：设计方案原文与《实现说明》（规则解释点、验收清单映射）。
- `artifacts/`：截图输出（不纳入版本管理）。
